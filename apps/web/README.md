# Smart EDU Console & Portal (`apps/web`)

Next.js App Router + TypeScript strict + Tailwind (`@smart-edu/ui-tokens`) + TanStack Query + Recharts + Phosphor Icons.

## Routes
- `/sign-in` — unified sign-in, SSO, and staff MFA
- `/console` — role-aware dashboards, `/console/roles`, `/console/audit-logs`, `/console/settings`
- `/portal` — isolated student & parent portal
